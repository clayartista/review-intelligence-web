## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

The development command also starts the Computer Vision API on
`http://127.0.0.1:8001`. Install its dependencies into the Python environment
you want to use:

```bash
python -m pip install -r backend/requirements-vision.txt
```

If that environment's Python executable is not on your `PATH`, set
`VISION_PYTHON` to its full path before running `npm run dev`. In PowerShell:

```powershell
$env:VISION_PYTHON = "C:\path\to\python.exe"
npm run dev
```

To run the services separately, use `npm run dev:next` and `npm run dev:vision`
in separate terminals.
